# Signal Desk demo

Run the web demo from the package directory:

```powershell
python -m pip install -e ".[dev]"
python web_demo/server.py
```

Open `http://127.0.0.1:8765`.

## 工作台卡片式布局模板

真后端工作台（`static/index.html` + `static/real.js` + `static/real.css`）采用统一的
**卡片式设计**：整页由六个功能卡片构成，卡片之间只通过固定位置和少量联动规则协作。
其他章节工作台需要类似的「提问 → 选方法 → 调参 → 看结果」页面时，可直接套用这套模板。

### 页面结构总览

```text
┌────────────────────────────────────────────────────────────┐
│ ① 大类方法选择框（顶部横条，独立于下方网格）                      │
│    选择分类   [01 白盒检测] [02 黑盒检测] [03 幻觉缓解]           │
└────────────────────────────────────────────────────────────┘
┌─────────────────────────────────┬──────────────────────────┐
│                                 │ ③ 小类方法选择框（右上）       │
│ ② 模型问答框（左，跨第 1–2 行）     │   按教材分类分组的方法列表     │
│    消息列表 + 输入栏              │   + 「开始检测 / 缓解」按钮    │
│    高度 = 右侧两卡片之和           ├──────────────────────────┤
│                                 │ ④ 参数设置框（右下）           │
│                                 │   抽样参数 + 方法额外参数      │
└─────────────────────────────────┴──────────────────────────┘
┌────────────────────────────────────────────────────────────┐
│ ⑤ 输出结果框（第 3 行，横跨整行；仅需要抽样的方法显示）            │
├────────────────────────────────────────────────────────────┤
│ ⑥ 检测结果框（第 4 行，横跨整行；结果标签页 + 结果卡片）           │
└────────────────────────────────────────────────────────────┘
```

网格实现（`real.css` 的 `.tut-shell`）：两列 `minmax(0, 1fr) + 320px` 侧栏 × 四行；
左栏问答框 `grid-row: 1 / 3` 跨两行，⑤⑥ 各占一整行。窄屏（≤1080px）退化为单列，
六个卡片按 ①→⑥ 的 DOM 顺序纵向堆叠。

### 卡片清单

| # | 卡片 | DOM（`index.html`） | 网格位置 | 职责 |
|---|---|---|---|---|
| ① | 大类方法选择框 | `nav.rd-tabs`（`.tut-page-tab[data-tab]`） | 顶部横条 | 在检测/缓解的大类（白盒、黑盒、缓解）之间切换；页签居中，左侧固定「选择分类」标签 |
| ② | 模型问答框 | `section.rd-panel-chat` | 第 1–2 行 · 左列（跨两行） | 提示词输入（预设下拉 + 生成长度）、流式生成、回答记录；回答气泡可点选为检测目标 |
| ③ | 小类方法选择框 | `aside.rd-panel-side`（`#rd-methods`） | 第 1 行 · 右列 | 当前大类下的具体方法列表，按教材分类分组；底部是全宽的「开始检测 / 缓解」主按钮，其下为所选方法的论文出处行（论文题名 + 跳转教材对应小节的链接） |
| ④ | 参数设置框 | `section.rd-panel-params`（`#rd-sampling`、`#rd-params`） | 第 2 行 · 右列 | 抽样参数（样本数 / 隐状态层）+「抽样」按钮 + 所选方法的额外参数表单；高度随内容伸缩，无额外参数的方法居中显示「该方法无需额外参数」 |
| ⑤ | 输出结果框 | `section.rd-panel-samples`（`#rd-samples`） | 第 3 行 · 横跨整行 | 抽样得到的独立回答列表；是**条件卡片**，仅需要抽样的方法显示 |
| ⑥ | 检测结果框 | `section.rd-panel-result`（`#rd-result-tabs`、`#rd-result`） | 第 4 行 · 横跨整行 | 检测/缓解结果的展示与多方法结果切换 |

### 排布与交互规则

1. **大类在上，小类在右上，输入在左**：大类切换（①）放最顶；当前大类的方法（③）
   和参数（④）固定在右侧 320px 窄栏；与模型对话的主区域（②）占左侧宽栏并跨两行，
   高度锁定为右侧 ③+④ 两卡片之和——消息变多时在消息列表内部滚动，不撑高整卡。
2. **切大类 = 换一套方法，不换数据**：切换 ① 会重置当前选中的方法和参数表单（③④），
   但问答记录（②）和检测结果（⑥）保留——检测结果按回答记录存取，跨页签可回看。
3. **检测对象是「回答记录」，不是输入框**：②里每条模型回答登记为一条记录；
   生成新回答后自动回到「检测最新一条」，点击任意回答气泡可手动改选检测目标
   （再点一次取消）。③④⑥ 的运行与结果都作用于当前选中的记录。
4. **方法列表跟随教材分类**：③ 内按教材的分类小标题分组（如「基于词元概率检测」），
   每组下是可点选的方法条目：选中高亮，超出当前模型能力的方法置灰。选中方法后
   ③ 主按钮上方展示对应论文出处链接（详见规则 9）。
5. **参数默认值只占位、不回填**：④ 中数值参数的默认值仅作灰色 placeholder，
   只有用户真正填写过的值才回填（localStorage 按大类+方法记忆）；未填写的参数
   不随请求回传，由后端取默认值。
6. **输出结果框按需出现**：⑤ 只在该方法需要多条独立样本时出现（黑盒一致性类、
   白盒表征分析类）；隐藏时 ⑥ 自动上移一行补位（`.tut-shell.no-samples`），不留空行。
7. **运行按钮有解锁门槛**：③ 底部主按钮在「已选方法 + 数值参数填全 + 需要抽样的
   方法已完成抽样」全部满足前保持禁用；运行失败的错误信息会即时显示在 ⑥。
8. **结果按记录归档、按方法覆盖**：⑥ 内同一回答的多个方法结果都保留，顶部胶囊
   标签切换；同一方法重跑覆盖旧结果；运行错误即时显示，不写入结果列表。
9. **方法配套论文与教材链接**：选中方法后，③ 的主按钮上方出现一行绿色链接
   「📄 教材 6.5.x.x 小节名 ↗」，点击在新标签页打开教材网页并锚定到对应小节，
   例如 `https://trustllm.trustaid.net/docs/llm/chapters/chapter-6/6-5/#基于词元概率检测`；
   悬停可查看该方法对应的论文全称。映射关系维护在 `real.js` 的 `PAPER_REFS`
   （16 个方法 ↔ 论文 ↔ 教材 6-5 小节）；未选方法时该行隐藏。
