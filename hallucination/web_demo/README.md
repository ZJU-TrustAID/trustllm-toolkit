# Signal Desk demo

Run the web demo from the package directory:

```powershell
python -m pip install -e ".[dev]"
python web_demo/server.py
```

Open `http://127.0.0.1:8765`.

## 工作台卡片式布局模板

**设计目标：同一页面，双模式可切换。** 页面顶部固定一条
「选择模式」横条（⓪，逻辑在 `static/mode.js`），要求在**同一个页面**内提供
两个版本并随时切换：

- **01 预设回放**（离线）：浏览预置教学场景，不加载模型、不占 GPU，方法结果
  全部来自离线预设目录；
- **02 实时模型**（在线）：下方五卡片的真后端工作台——与真实模型对话并运行
  检测 / 缓解；「实时模型」按钮小字每 5 秒轮询 `GET /api/real/status` 标示服务状态。

当前状态：横条已就位且默认停在「预设回放」，但**切换尚未接通功能**——点击只更新
右侧说明文字，页面主体仍是实时工作台。把预设回放版本接入同一页面是下一步的既定
工作，素材均已保留并在服务端可用（`static/tutorial.js` 预设前端 +
`GET /api/catalog`、`POST /api/method` 离线接口，零模型调用），届时只需挂载素材
并在两种面板间切换（详见规则 10）。

真后端工作台（`static/index.html` + `static/real.js` + `static/real.css`）
采用统一的**卡片式设计**：五个功能卡片之间只通过固定位置和少量联动规则协作。
其他章节工作台需要类似的「提问 → 选方法 → 调参 → 看结果」页面时，可直接套用
这套模板。

### 页面结构总览

```text
┌────────────────────────────────────────────────────────────┐
│ ⓪ 选择模式框（顶部横条，同越狱攻击工具包）                        │
│    选择模式  [01 预设回放 离线·不加载模型] [02 实时模型 <状态小字>] → 右侧说明 │
├────────────────────────────────────────────────────────────┤
┌─────────────────────────────────┬──────────────────────────┐
│                                 │ ② 方法选择框（右上）           │
│ ① 模型问答框（左，跨第 1–2 行）     │   三个大类折叠分组              │
│    消息列表 + 输入栏              │   （白盒检测 / 黑盒检测 /        │
│    高度 = 右侧两卡片之和           │    幻觉缓解），展开大类 →        │
│                                 │   教材小分类 + 方法列表          │
│                                 ├──────────────────────────┤
│                                 │ ③ 参数设置框（右下）           │
│                                 │   抽样参数 + 方法额外参数      │
└─────────────────────────────────┴──────────────────────────┘
┌────────────────────────────────────────────────────────────┐
│ ④ 输出结果框（第 3 行，横跨整行；仅需要抽样的方法显示）            │
├────────────────────────────────────────────────────────────┤
│ ⑤ 检测结果框（第 4 行，横跨整行；结果标签页 + 结果卡片）           │
└────────────────────────────────────────────────────────────┘
```

网格实现（`real.css` 的 `.tut-shell`）：两列 `minmax(0, 1fr) + 320px` 侧栏 × 四行；
左栏问答框 `grid-row: 1 / 3` 跨两行，④⑤ 各占一整行。窄屏（≤1080px）退化为单列，
卡片按 ⓪→①→②→③→④→⑤ 的 DOM 顺序纵向堆叠。

### 卡片清单

| # | 卡片 | DOM（`index.html`） | 网格位置 | 职责 |
|---|---|---|---|---|
| ⓪ | 选择模式框 | `nav.mode-tabs`（`#mode-demo`/`#mode-live`，逻辑在 `static/mode.js`） | 顶部横条（最顶） | 「预设回放 / 实时模型」模式选择（样式同越狱攻击工具包）；当前仅做样式与状态指示（见规则 10） |
| ① | 模型问答框 | `section.rd-panel-chat` | 第 1–2 行 · 左列（跨两行） | 提示词输入为**胶囊式输入条**：最左「+」按钮弹出预设提示词列表与生成长度，中间输入框随内容自动增高，最右「↑」圆形按钮发送；流式生成、回答记录，回答气泡可点选为检测目标。输入条上方是「上下文」卡（仅缓解大类显示）：CAD 选中时卡片高亮、提示必填（后端对空上下文直接报错，运行前也会前置拦截），其余缓解方法可留空 |
| ② | 方法选择框 | `aside.rd-panel-side`（`#rd-methods`） | 第 1 行 · 右列 | 三个大类折叠分组 `details.rd-cat`（白盒检测 / 黑盒检测 / 幻觉缓解，同越狱攻击工具包的方法分组）：展开大类即切换并显示组内方法，方法按教材分类小标题分组；底部是全宽的「开始检测 / 缓解」主按钮，其下为所选方法的论文出处行（论文题名 + 跳转教材对应小节的链接） |
| ③ | 参数设置框 | `section.rd-panel-params`（`#rd-sampling`、`#rd-params`） | 第 2 行 · 右列 | 抽样参数（样本数 / 隐状态层）+「抽样」按钮 + 所选方法的额外参数表单；高度随内容伸缩，无额外参数的方法居中显示「该方法无需额外参数」 |
| ④ | 输出结果框 | `section.rd-panel-samples`（`#rd-samples`） | 第 3 行 · 横跨整行 | 抽样得到的独立回答列表；是**条件卡片**，仅需要抽样的方法显示 |

### 排布与交互规则

1. **方法在右上，输入在左**：方法列表（②）和参数（③）固定在右侧 320px 窄栏；
   与模型对话的主区域（①）占左侧宽栏并跨两行，高度锁定为右侧 ②+③ 两卡片之和——
   消息变多时在消息列表内部滚动，不撑高整卡。
2. **大类 = 右侧折叠分组，展开即切换**：② 的三个大类（白盒检测 / 黑盒检测 / 幻觉缓解）
   是可折叠分组（样式同越狱攻击工具包的方法分组，编号 01/02/03 保留），首次打开 /
   刷新时默认全部收起；展开某个大类会收起其余（手风琴），同时重置当前选中的方法和
   参数表单（②③）；但问答记录（①）和检测结果（⑤）保留——检测结果按回答记录存取，
   跨大类可回看。
3. **检测对象是「回答记录」，不是输入框**：①里每条模型回答登记为一条记录；
   生成新回答后自动回到「检测最新一条」，点击任意回答气泡可手动改选检测目标
   （再点一次取消）。②③⑤ 的运行与结果都作用于当前选中的记录。
4. **方法列表跟随教材分类**：② 的大类展开后按教材的分类小标题分组（如「基于词元概率
   检测」），每组下是可点选的方法条目：选中高亮，超出当前模型能力的方法置灰。
   选中方法后 ② 主按钮上方展示对应论文出处链接（详见规则 9）。
5. **参数默认值只占位、不回填**：③ 中数值参数的默认值仅作浅灰 placeholder
   （明显浅于已填数值）；只有用户真正填写过的值才回填（localStorage 按大类+方法
   记忆）；未填写的参数不随请求回传，由后端取默认值。
6. **输出结果框按需出现**：④ 只在该方法需要多条独立样本时出现（黑盒一致性类、
   白盒表征分析类）；隐藏时 ⑤ 自动上移一行补位（`.tut-shell.no-samples`），不留空行。
7. **运行按钮有解锁门槛**：② 底部主按钮在「已选方法 + 数值参数填全 + 需要抽样的
   方法已完成抽样」全部满足前保持禁用；已发送提示词且已选方法时，若仅因数值参数
   未填全而禁用，按钮下方提示行显示「先在下方设置参数，再开始运行」；运行失败的
   错误信息会即时显示在 ⑤。
8. **结果按记录归档、按方法覆盖**：⑤ 内同一回答的多个方法结果都保留，顶部胶囊
   标签切换；同一方法重跑覆盖旧结果；运行错误即时显示，不写入结果列表。
9. **方法配套论文与教材链接**：选中方法后，② 的主按钮上方出现一行绿色链接
   「📄 教材 6.5.x.x 小节名 ↗」，点击在新标签页打开教材网页并锚定到对应小节，
   例如 `https://trustllm.trustaid.net/docs/llm/chapters/chapter-6/6-5/#基于词元概率检测`；
   悬停可查看该方法对应的论文全称。映射关系维护在 `real.js` 的 `PAPER_REFS`
   （16 个方法 ↔ 论文 ↔ 教材 6-5 小节）；未选方法时该行隐藏。
10. **⓪ 的设计目标是双模式入口，当前仅为状态指示**：按钮与说明文字沿用越狱攻击
   工具包的样式与文案语义，默认停在「预设回放」；点击切换只更新右侧说明文字与
   `aria-pressed`，下方工作台不随模式变化。预设教学素材（`static/tutorial.js` +
   `/api/catalog`、`/api/method`，零模型调用）在仓库中保留但尚未接入本页，接入后
   ⓪ 升级为真正的双模式入口：同一页面在「预设回放面板 ↔ 实时工作台面板」之间
   切换。「实时模型」按钮的小字每 5 秒轮询 `GET /api/real/status`：已加载显示
   模型名（仅末级目录/仓库名），已配置未加载显示「模型待加载」，可达但未配置
   模型显示「未配置模型」，服务不可达显示「模型服务离线」。
