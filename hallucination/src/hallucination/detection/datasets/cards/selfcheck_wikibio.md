# selfcheck_wikibio

Adapter for [`potsawee/wiki_bio_gpt3_hallucination`](https://huggingface.co/datasets/potsawee/wiki_bio_gpt3_hallucination), the sentence-level dataset released with SelfCheckGPT.

- Source: SelfCheckGPT authors.
- Access: optional Hugging Face `datasets` dependency and network access.
- Mapping: `gpt3_text` -> `response`, `gpt3_text_samples` -> `samples`, `gpt3_sentences` -> `units`, `annotation` -> `unit_labels`.
- Scope: English Wikipedia-style biography passages generated by GPT-3. It is not a general factuality benchmark and should not be used to select Chinese production thresholds.

Readers must consult the source data card, license, and citation requirements before use. The toolkit does not redistribute the dataset.
