# 将 Jailbreak-tookit 接入 hub（第三章 · 越狱攻击）— 环境名改为 `jailbreak-toolkit`

## Context

仓库其余章节（hallucination/6、guardrail/4-5、marksec/7）均已通过「chapter.yaml 清单 + hub_adapter + 章节前端」模式接入 `hub/`。Jailbreak-tookit（11 种越狱方法：template/role_play/task_disguise/rule_rewrite/context/base64/caesar/red_teaming/autodan/gcg/cold_attack，包 `textbook_toolkit`）已有功能完整的本地教学网站（`website/server.py` + `dist/`），但风格为紫色主题、与 hub 不统一，且未接入 hub。目标：**功能保持与现有工具包完全一致**（11 方法、预设示例、进度阶段、损失曲线、人工判读），**视觉改为 hub 设计语言**（暖纸底 `#f2f0ea`、墨绿 `#1d2a24`、青绿主色 `#0e9f6c`、蓝色交互 `#2563eb`、卡片圆角阴影等，取自 `hub/src/trustllm_hub/static/styles.css`），并按 hub 清单协议接入。**按用户要求：conda 环境命名为 `jailbreak-toolkit`。**

## 实施步骤

### 0. 创建 conda 环境 `jailbreak-toolkit`（不存在，需新建）
```bash
conda create -n jailbreak-toolkit python=3.11 -y
conda run -n jailbreak-toolkit pip install -e '/data2/trustllm/Jailbreak-tookit[optimization,evolution,dev]'
conda run -n jailbreak-toolkit python -m nltk.downloader wordnet   # AutoDAN 同义词
```

### 1. 抽取共享实验执行器（消除重复，保证两处行为一致）
- 新建 `Jailbreak-tookit/src/textbook_toolkit/lab.py`：把 `website/server.py` `Runtime.run()` 中「token 长度校验 → 基线回答 → 按方法构造/优化输入 → 最终回答 → 输出 dict」的核心逻辑抽成 `run_experiment(backend, payload, *, max_new_tokens, eval_batch_size, model_name, location, progress=None)`（torch 相关 import 留在函数内，保持「导入包不加载 torch」的现有约束）。输出 dict 结构与现在逐字段一致（smoke_test 有断言）。
- 修改 `Jailbreak-tookit/website/server.py`：`Runtime.run()` 改为调用 `lab.run_experiment`，行为不变；新增 `--config` 参数（读取 hub 渲染的 JSON：`model`/`device`/`dtype`/`max_new_tokens`/`web.host`/`web.port`，与 MarkSec `src/api/serve.py` 同款模式）：
  - `web.trust_proxy: true`（chapter.yaml 注入）时放宽 Host/Origin 校验——否则经 hub 反代的 POST 会因 Origin=`127.0.0.1:8680` 被 403。独立运行（无 `--config`）时校验保持不变，`website/smoke_test.py` 的 403 断言不受影响。
  - 模型为 HF 仓库名（非本地目录）时不再强制 `HF_HUB_OFFLINE/TRANSFORMERS_OFFLINE`（本地目录仍离线加载）。
  - `dtype: auto` 映射：CPU→float32，CUDA→bfloat16；`device: auto` → cuda 优先。

### 2. hub 适配器（批量/YAML 复现入口）
- 新建 `Jailbreak-tookit/src/textbook_toolkit/hub_adapter.py`，CLI `--config <hub统一YAML> --output-dir <会话目录>`（照抄 `MarkSec/src/hub_adapter.py` 骨架）：
  - 读 `models.default`（`api` 来源直接报错，GCG/COLD 需本地梯度权重）、`common.device/dtype/seed`、`chapter_params` 并严格校验（method ∈ 11、query ≤480 字、target ≤100、steps ∈ {3,6,10}、mode、role ≤60、seed ≤180 无花括号——与网站 `validate()` 同规则）。
  - 加载 `CausalLM`，调用 `lab.run_experiment`（`common.seed` 接入优化器 config，默认 0 与现状一致），写出三个文件：`results.json`（原始结果）、`report.md`（问题/基线/构造输入/攻击后回答/损失变化表/结论）、`result.json`（hub 信封 `{status, summary, blocks:[markdown|table|code], artifacts, data}`；失败时 status=failed 退出码 2）。进度用 `flush=True` 打印供 run.log 流式展示。

### 3. 接入清单
- 新建 `Jailbreak-tookit/chapter.yaml`（对照 `MarkSec/chapter.yaml`）：
  - `chapter: 3`、`title: 越狱攻击`、`toolkit: jailbreak`
  - `frontend.mode: proxy`，`server.port: 8784`（约定：8781/8782/8783 已占用），`ready_path: /api/health`，`command: conda run -n jailbreak-toolkit python website/server.py --config {config}`，`config:` 注入 `model/device/dtype/web.host + web.trust_proxy`，`config_port_key: web.port`；**不设 autostart**（该服务启动即预载模型，由用户点击启动）
  - `backend.command: conda run -n jailbreak-toolkit python -m textbook_toolkit.hub_adapter --config {yaml} --output-dir {output_dir}`，`timeout: 7200`
  - `models`: role `default`，`accepts: [local_path, hf]`，默认 `hf HuggingFaceTB/SmolLM2-135M-Instruct`（CPU 可跑，models/ 下也有本地副本可选）
  - `params`: method（11 枚举，默认 role_play）、query（默认取站内欺凌预设文案）、target、steps（enum 3/6/10）、mode、role、seed、max_new_tokens；单值适用的加 `when:`（role→role_play、seed→autodan、mode→cold_attack）；target/steps 无法用单值 when 表达「三种优化器任一」，保持常显并在标题注明
  - `results: {primary: report.md, files: [report.md, results.json]}`

### 4. 前端改色（功能零改动）
- `website/dist/styles.css`：保持全部选择器/结构不变，仅替换设计变量与颜色值为 hub 调色板（`--bg #f2f0ea`、`--panel #fbfaf6`、`--line #ddd8cb`、`--ink #1d2a24`、accent 紫→青绿 `#0e9f6c`、交互蓝 `#2563eb`、radius 10px、hub 阴影、hub 字体栈 14px PingFang SC）。
- `website/dist/app.js`：仅改 `drawTrace()` 里 6 处硬编码 SVG 颜色（网格 `#e9e2ef`→暖灰、轴线字→`#8a948b`、折线紫 `#9473ad`→青绿、选中点 `#5c468e`→深青绿）。
- `website/dist/favicon.svg`：紫色同步换青绿。`index.html` 结构不动。

### 5. 文档
- 根 `README.md`：章节表第三章行改为 ✅ 已接入 hub + 链接；仓库结构清单补 `Jailbreak-tookit/` 行。
- `Jailbreak-tookit/README.md`：新增「hub 集成」小节（环境创建、经 hub 启动、独立运行仍然可用）。

## 验证

1. **清单/配置校验**：用 `trustllm_hub.registry.load_manifest` 加载新 chapter.yaml、`schema.validate_config` 验证样例 YAML；跑 `hub/tests` 既有测试确保无回归。
2. **网站独立 E2E**：`conda run -n jailbreak-toolkit python website/server.py --port 4173 --model /data2/trustllm/models/SmolLM2-135M-Instruct --device cpu`，跑 `website/smoke_test.py`（11 方法 + 403/404 保护断言）。
3. **hub 适配器**：手写最小 YAML（role_play，本地 SmolLM2，CPU）直接跑 `python -m textbook_toolkit.hub_adapter`，检查 result.json/report.md；再跑一次 gcg（steps=3）验证优化器路径。
4. **hub 端到端 + 视觉**：启动 `python hub/start.py`，确认总览页出现第三章卡片；经 hub API 启动章节服务，用浏览器截图总览页/工作台（iframe 内改色后的前端）与运行页，对照 hub 既有页面核对色调统一、功能控件齐全。
5. 结束后 hub 保持运行（当前是停止状态），向用户报告访问端口 8680。
