# 数据卡：合成凤尾鱼观测语料

> 教材 2.1 节以「水产研究机构的凤尾鱼观测数据」作为贯穿案例。真实观测数据涉及
> 机构版权，**不能**随教学工具包分发，因此本目录下的数据全部为**模板 + 固定随机
> 种子合成的领域风格文本**。

## 文件

| 文件 | 条数 | 用途 |
|---|---|---|
| `fugu_corpus.jsonl` | 96 | **受保护语料**：凤尾鱼观察记录，每条 34–51 个汉字（要求 30–80），每行 `{"doc_id","text"}` |
| `fugu_public_mix.jsonl` | 50 | **公共风格混合语料**：与水产无关的通用文本，用于混合训练语料 / 对照文本 / 质量评估的参考语料 |

## 来源与合成方式

* **生成脚本**：`scripts/make_synthetic_corpus.py`（只用标准库）；
* **随机种子**：`20260801`，同一脚本可逐字节复现；
* **领域风格**：观测站、水温、盐度、体长、洄游、网具、样本编号等水产观测要素；
* **公共语料**：社区图书馆、城市公交、茶园管理等通用话题，不含水产领域词；
* **不含真实个人信息**：没有真实人名、机构名、水域编号；文中的观测数值、虚构机构
  （如「蓝鳍观测站」「雾港水文档案」）均为程序随机生成，与现实无关。

重新生成::

    python3 scripts/make_synthetic_corpus.py --out-dir data --seed 20260801
